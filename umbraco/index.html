What stands between Umbraco 13 and 17

  • End of life on December 14, 2026, and the .NET 8 runtime under Umbraco 13 loses security patches on November 10, 2026. Umbraco 17 runs on .NET 10.
  • A new backoffice. AngularJS was removed in Umbraco 14. Custom dashboards, property editors and block views have to be rebuilt as Web Components.
  • Community packages need a release built for the new backoffice. Some still have none.
  • Removed editors. Nested Content, Grid Layout, the legacy Media Picker and macros are gone, and TinyMCE is replaced by Tiptap in 16.
  • Code changes across four major versions: System.Text.Json, the Management API, no XPath, no snapshots, dates in UTC.

How I work

Everything happens in writing, on your schedule. A 15-minute call is available if you want one, never required.

  1. Read-only access. Add a read-only collaborator on GitHub, Azure DevOps or GitLab, or send a zip. No production credentials and no secrets.
  2. The work gets done. A set of AI coding agents does the scanning, the code changes and the test runs. I review every change and sign off before you see it.
  3. You get a pull request. With notes on what changed, what to watch on deploy and the results of your own tests. Without write access, you get a patch file.
  4. You deploy. I never touch production: no deploys, no production databases, no infrastructure changes. You merge and release when it suits you.

The job is accepted when the solution builds and your existing tests pass. Tests that already failed before are listed in the notes and stay out of scope. No automated tests? We agree on a short smoke checklist before I start, and that becomes the acceptance criterion.

FAQ

Can we go straight from 13 to 17?

Yes. Umbraco documents a direct path from the latest 13.x to the latest version. I upgrade to the latest 13.x first, then to 17, on a copy of your database.

How do you work with our content?

I run the upgrade against a database backup you provide, never against production. The content migrations are timed there so you know how long the go-live window needs to be.

A package we use has no Umbraco 17 version.

I tell you before starting, with the options: a replacement package, rebuilding the part you use, or waiting. If rebuilding goes beyond your tier, you get a quote first.

Which tier do I need?

Run Umbraco17Check and send me the report. I tell you the tier for free before you buy.
